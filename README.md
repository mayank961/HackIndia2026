🌟 PromptEnhance AI — Intelligent Prompt Optimization Tool

A lightweight AI-powered tool that improves any prompt by generating three optimized versions instantly.
Built for developers, creators, students, and anyone who wants better AI responses.

🚀 Features

🔍 Prompt Analysis (detects missing context & improves clarity)

✨ Generates 3 Enhanced Prompt Versions Automatically

💾 Persistent Prompt History (LocalStorage)

📤 Copy & Export (.txt) Support

🎨 Dark & Light Mode

⚡ Fast, responsive, modern UI using TailwindCSS

🧩 Pure frontend project — no backend needed
